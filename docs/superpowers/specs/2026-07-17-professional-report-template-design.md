# 观隅专业审视报告模板设计

## 目标

将观隅 PDF 导出升级为原创的正式研究报告模板。模板面向打印、归档、审阅和引用，不复制 McKinsey、BCG、Bain、投行、四大或律所的视觉识别、商标、Logo、专有配色或页面资产。

## 研究归纳

公开咨询、投行、会计师事务所和律所研究材料呈现出一套共同的行业语言：封面承担识别与文件元数据；前页先给结论与关键指标；正文通过稳定的章节层级、短段落、数据图表与证据表支持阅读；来源和披露信息可追溯；页眉、页脚、页码和报告编号便于内部传阅与归档。

参考样本：

- BCG 的公开白皮书使用主题页、正文论证、作者与联系信息、版权页的清晰分层。
- Morgan Stanley 的公开研究产品强调面向使用场景的研究分层与简化可读的布局。
- Deloitte 与 KPMG 的公开研究以执行摘要、少量重点结论和可行动的信息结构组织内容。
- Skadden 的年度洞察采用目录、议题分区、要点和法律披露，使长文可定位、可引用。

## 原创模板：观隅专业审视报告 v1

### 信息结构

1. 封面：观隅名称、报告名称、新闻标题、来源、编号、版本、日期、模型、语言与免责声明。
2. 执行摘要：新闻摘要、一句话结论、关键发现、最重要待核验事项。
3. 核心指标：五项评分与简短阅读说明。
4. 审视正文：关键发现、原始主张、支持证据、信息缺口、利益关系、替代解释、验证路线图、继续追问、AI 补充内容。
5. 来源与引用：来源编号、标题、URL 与可核验信息。
6. 附录：原文节选与截断说明。

目录只在正文超过六页时生成；短报告不生成无价值目录。

### 排版规则

- 页面：A4 纵向；左右 20 mm 左右，上 20 mm、下 18 mm 左右的等效留白。
- 字体：每份文件只使用一种主字体。中文、繁体中文、日语和韩文报告嵌入已在生产导出中验证的 Noto Sans SC；英语、德语和意大利语等拉丁语言报告使用 PDF 标准 Helvetica。避免在同一导出中混合字体子集，保证复制、搜索和跨设备阅读；不使用服务器字体路径作为文档内容。
- 正文：10.0–10.5 pt 等效字号，1.45–1.55 倍行距；标题层级显著且不超过三级。
- 行宽：正文单栏优先；仅指标、短证据条目或数据矩阵使用双栏。
- 防孤行：标题必须与后续至少一行内容同行；条目卡不在中间截断。
- 页眉：观隅 + 报告短标题；页脚：报告 ID、生成日期与“当前页 / 总页数”。

### 色彩和图表

- 主色使用观隅自己的低饱和蓝灰和暖灰；黑白打印时保持文字和边框可辨。
- 可信度、完整度、证据强度为蓝灰；叙事倾向为琥珀；推测不确定性为暗红。
- 不使用霓虹、渐变、大面积阴影、三维图表或品牌模仿性配色。
- 每个图表或指标组均直接标注数值，并保留一句解释与数据限制说明。

### 证据与归档

- 关键判断以编号来源表示，例如 `[S1]`；正文与来源列表使用同一编号。
- 来源条目保留标题、来源、URL、证据等级与核验状态；不把模型推断写成来源。
- 每个导出版本固定报告编号、版本和生成时间；文件保持文字可复制、可搜索。

## 不在本次范围

- 不改变九镜审读法、评分定义、报告字段或生成模型提示词。
- 不修改导出权限、点数、数据库结构或支付逻辑。
- 不加入第三方机构的 Logo、标志性图形、配色、模板或专有措辞。
