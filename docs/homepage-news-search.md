# 首页新闻检索与分析

首页以全宽工作区依次展示新闻搜索和报道分析。网页链接输入与可编辑正文同时显示；既可获取正文，也可直接粘贴或修改正文。RSS 收入按需展开的订阅入口，不再固定占据右侧一栏。

## 用户流程

1. 输入 2–128 个 Unicode 字符的关键词，选择当前可用的搜索来源及时间范围。
2. 列表展示最多 10 条结果，含媒体/域名、可确认的发布时间、摘要、原文链接及“分析这篇”。未知日期明确标注，不根据摘要或相对时间猜测。去掉常见追踪参数后按 URL 去重，保留路径大小写。
3. 点击“分析这篇”自动带入链接并读取正文。搜索摘要不作为新闻正文送给模型。
4. 访客在这一步登录；关键词、结果和选择只在当前标签页暂存，恢复窗口 30 分钟。邮箱验证码首次注册、已有密码和通行密钥登录均可通过固定的 `/login?callbackUrl=/` 回到首页，继续读取所选报道；只允许这一明确的内部返回目标。
5. 展示正文及现有后端报价，确认后点击“开始观隅分析”。模型不可用、费用无法确认或点数不足时禁用开始按钮；读取失败不创建分析任务。模型任务和成功保存后的计费沿用原逻辑，客户端防止连续点击重复提交。
6. 来源链接保存于报告 JSON 的 `meta.sourceUrl`，在原文区可打开。非所有者查看报告时，该字段遵循原文公开设置，默认不公开。

## 来源和管理员设置

在“账号管理 → 系统管理 → 首页新闻搜索”设置：

- **首页默认来源**：免费网页搜索或 DeepSeek API，与报告分析模型/报告核验的来源选择独立。
- **平台 API 密钥来源**：复用模型管理里已经保存的 DeepSeek 搜索密钥，不复制密钥，也不把密钥发到浏览器。所选配置须启用、对用户可见、未归档且已保存搜索密钥。保存新密钥后可刷新配置列表。
- **平台 API 每日调用上限**：默认 200，允许 1–10000。按北京时间及所选配置计数；记录的是上游调用尝试，包括失败尝试，缓存命中不占额度。耗尽时提示改用免费搜索。平台承担服务商搜索费用，不额外扣用户搜索点数。

免费工具查询配置的 SearXNG `categories=news`，并使用 Bing News RSS；两个来源有结果时交错展示、按原文链接去重。没有其他可用结果且 Bing RSS 不可用时尝试 Bing News 网页，新闻来源都不可用时提示失败，不再把普通网页结果当作新闻。RSS 中的媒体、原文链接和明确发布时间会进入结果列表。时间范围同时传给上游，并根据明确的发布时间再次筛选；没有可确认日期或不在范围内的报道不会出现在有时间限制的结果中。新闻索引仍可能漏报，也无法保证所有报道都适合自动提取全文。

DeepSeek API 仍受部署级 `GUANYU_ALLOW_PAID_SEARCH=true` 开关控制。访客只能使用免费来源。登录用户如有有效 Pro（含兼容永久 BYOK）或管理员权限，并保存了个人 DeepSeek 搜索密钥，优先使用其个人密钥；否则使用管理员开放的平台配置。无权限的个人密钥不参与解析。首页始终标明密钥由个人还是平台提供。

DeepSeek 的搜索接口面向普通网页：首页先查询免费新闻索引，再只展示同时出现在该索引和 DeepSeek 结果中的原文链接，因此结果可能较少；没有新闻候选时不调用付费接口。DeepSeek 当前接口未提供项目可依赖的时间筛选，因此选择该来源时仅允许“不限时间”。失败时提供显式免费搜索按钮；免费搜索不会自动调用收费 API。

## 缓存、限额和成本

- PostgreSQL 的短时共享缓存：有结果 3 分钟、空结果 30 秒。缓存键用 HMAC 表示查询、语言、时间、来源和密钥作用域；不保存明文关键词或密钥。个人密钥缓存按账号隔离，平台密钥缓存可在同一配置下共享；密钥轮换使旧缓存失效。
- 数据库锁和 30 秒租约合并相同并发查询；等待者收到 409 与 Retry-After，由页面有限次重试。过期租约可重新取得，旧执行者不能覆盖新缓存。
- 单网络 5 分钟最多 12 次访客请求或 30 次已登录请求（含重试）；收费搜索每账号每 10 分钟最多 10 次新的上游尝试，另受平台每日限额约束。
- 外部调用写入 `ModelUsageEvent.operation=news_search`。独立检索不调用大模型，成本口径为搜索费用估计；缓存不重复记录上游调用。不创建分析扣费账单。
- 查询通过 POST 请求发送，不进入站内 URL。缓存结果会短时保存公开标题、链接和摘要，过期缓存由现有每日 `/api/cron/privacy` 清理；有效期与物理清理时间不同。

## 部署

先应用 `prisma/migrations/20261025_news_search/migration.sql`，再启动新代码。新增 AppSetting 的三个字段和 NewsSearchCache 表/索引，不修改旧报告、用户余额或密钥。遵循现有 `prisma migrate deploy` 流程；早期 db-push 建库需先完成迁移历史基线，不要重置生产库。空库验证使用 `prisma db push`。

默认无需收费 API。可选部署变量继续复用：

```dotenv
WEB_RESEARCH_SEARXNG_URL=https://your-searxng.example
WEB_RESEARCH_ALLOW_PRIVATE_SEARXNG=false
GUANYU_ALLOW_PAID_SEARCH=false
```

只有部署者控制的内网 SearXNG 才应启用私网访问。保留现有 SSRF、重定向、响应体和超时限制，正常抓取不放开私网。生产公开请求依赖可信代理限流（Vercel 自动识别；自托管沿用 TRUST_PROXY_HEADERS 配置）。

如果页面提示“新闻搜索服务配置不完整”，检查服务日志中的 `[news-search]` 代理配置提示。自托管部署应让可信反向代理覆盖 `X-Forwarded-For` 和 `X-Forwarded-Proto`，再设置 `TRUST_PROXY_HEADERS=true`；不要在没有可信代理保护的服务上启用该选项。

## 验证与限制

`npm run test:news-search` 覆盖 RSS 的原文链接、来源和日期，新闻来源聚合去重、时间过滤、拒绝普通网页回退及 DeepSeek 的新闻索引交叉校验；还覆盖登录恢复、隐私权限、缓存并发、限额与计费，已纳入 CI。旧版普通网页回退的缓存和本地搜索草稿不会继续作为新闻结果显示。

浏览器 QA 使用受控的 SearXNG 兼容 HTTP 服务和本地模型完成真实任务保存/单次扣费；正文提取响应使用虚构报道 fixture。也检查桌面/手机、登录恢复、空结果、旧请求回写、来源故障、RSS 按需加载和管理员保存。真实 Bing News 页面另行获取并验证解析；云环境只支持代理外联，现有固定公网 IP 直连抓取在此环境受限。DeepSeek 使用测试响应验证，不产生真实计费调用。

免费引擎的页面结构、验证码、站点访问限制和搜索结果时效仍取决于上游。较大流量建议部署并维护 SearXNG；本版不承诺全文索引覆盖、分页、跨报道事件聚类或根据搜索摘要生成报告。
