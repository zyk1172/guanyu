# 首页新闻检索与分析

首页默认展示 RSS 图文新闻卡片，提供“热点 / 最新”、新闻源筛选、刷新和加载更多。新闻搜索位于顶部；手工分析表单默认收起，点击“粘贴文章分析”即可展开并聚焦正文。网页链接与可编辑正文仍在同一个表单中。

## 图文新闻与热点

- 配图先读取 RSS 的媒体缩略图、图片附件或正文插图；没有可用图片时，按需读取**同一篇报道**的 Open Graph、Twitter、NewsArticle 或文章正文图片。标题与摘要保留发布者原文，不调用模型编造摘要，也不自动翻译。
- 图片经签名的 `/api/news/image` 获取，禁止任意 URL 开放代理。逐跳校验公网 DNS 和重定向，限制超时、响应体、像素数及并发；只处理实际栅格图片，去除元数据后返回 640×360 WebP。失败时去掉图片位，不借用其他新闻的图片。正文提取的安全边界保持独立。
- **热点资格**：近 48 小时至少两家独立发布者关注同一话题，或者与近 24 小时免费 Google 新闻头条 RSS 匹配。按来源多样性、头条索引和时间衰减排序，不使用本站审读量、图片是否可用或收费搜索 API 决定资格。
- 事件匹配使用标题关键词、中文双字词、少量跨语言实体和明确命名事件，结合发布者摘要及发布时间。要求主题相似、时间接近，并检查组内所有报道，避免只因出现同一国家或人物而聚成热点。它是有限订阅源内的保守话题聚合，仍可能漏掉语义不同的标题，或把同一大事件的不同进展归为一组。
- 相同发布者的不同订阅源只计一次；卡片可展开核对实际来源及头条链接。单来源头条只标“新闻头条收录”。这是报道关注度依据，**不是全网热搜榜、阅读量或事实核验结论**。
- “最新”展开为单篇报道，按有效时间降序。超过 7 天的已知旧闻不进入推荐；缺失或异常未来日期不获得热点资格和新鲜度加权。没有热点依据时自动展示最新并说明原因。
- 推荐来源包括对话地球、The Conversation、Carbon Brief、德国之声、卫报和人民日报。新加入的三家只展示标题、来源、时间及原文链接。中文界面使用对话地球和德国之声的中文订阅，其他语言使用其英文订阅。已保存的管理员和个人订阅可以在账户设置中套用推荐来源。中文和英文 Google 新闻头条用于交叉匹配，任一索引故障不妨碍其他订阅源。
- 浏览、图片、热点聚合不消耗分析点数，不调用大模型或收费搜索。卡片分析价格来自现有当前模型报价，提交时服务端重新校验；自定义模型调用费用仍由对应服务商收取。

### 首页新闻缓存

- 公开首页快照存进既有 PostgreSQL `NewsSearchCache`。GitHub Actions 每小时第 7 分钟检查并预热中、繁、英三个新闻版本，默认使用仓库的 Vercel 生产域名。自托管可用仓库变量 `GUANYU_SITE_URL` 指向自己的部署，或用已有的定时任务访问相同的公开 GET 地址。调度排队可能推迟预热。
- 首页读取优先返回已有快照。跨小时后可在返回旧内容的同时后台更新，并用数据库租约合并并发刷新。个人订阅组合也按小时更新，访问该组合时按需生成。失败来源保留上次成功的标题，全源失败时继续使用旧快照，快照保留期为 7 天。
- 浏览器按语言和账号保存自己的快照，打开页面时先显示，再用条件请求检查服务端版本。点击“刷新”独立读取当前订阅源，结果只存入发起请求的浏览器。服务端发布更新版本后覆盖本地快照。同步期间保留列表、筛选和已展开的报道。手动刷新沿用可信代理限流，每个来源 IP 5 分钟最多 3 次。

## 小型采集的可行性与法律风险

观隅已经具备官方 RSS 定时刷新、去重、失败回退、单页正文提取，以及人民日报首页标题解析。对确有需求且发布者允许的站点，可以用同一套快照管道增加小型采集适配器。优先选官方 RSS、API 或授权索引。没有接口时，可从一个公开栏目起步，按小时发条件请求，仅提取标题、来源、时间及原文链接。每域独立限流并遵循 `robots.txt`，遇到 403、429、验证码或登录要求时暂停。沿用公网域名校验、逐跳重定向检查、体积和超时上限。此次新增源都使用官方订阅。

- **发布者条款。** 网上公开的 RSS 可能只授权个人阅读。ProPublica 的自动访问例外包含个人使用的 RSS 阅读器，Noema 的站点条款限制爬取。对话地球一般采用署名、非商业、禁止演绎许可，并另行限制图片等素材。应按发布者和具体素材核对授权；`robots.txt` 规定机器访问偏好。 [ProPublica 条款](https://www.propublica.org/terms-of-service) · [Noema 条款](https://www.noemamag.com/terms-of-use/) · [对话地球转载政策](https://dialogue.earth/zh/republishing/) · [RFC 9309](https://www.rfc-editor.org/rfc/rfc9309.html)
- **中国大陆法律。** 单纯事实与有独创性的文字、图片区分处理。公开分析中的适当引用应符合目的、署名和使用范围等要求。绕开技术措施取得、使用数据，也可能涉及反不正当竞争责任。向公众提供新闻转载服务时，应结合展示内容和运营范围评估互联网新闻信息服务许可要求。 [著作权法第 5、24 条](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html) · [反不正当竞争法第 13 条](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_3737890d856a4e44a8ea07c50c90c116.html) · [互联网新闻信息服务管理规定](https://www.cac.gov.cn/2017-05/02/c_1120902760.htm)
- **隐私和模型调用。** 先在仅账号可见的测试范围验证。首页快照以发现元数据为限。用户发起正文分析、向模型服务商传输正文及其个人信息、公开报告与原文附录要分别评估授权、保存期限和公开范围。适用中国个人信息保护规则时，也需核对模型接收方及数据出境要求。 [个人信息保护法第 27、38 条](https://www.miit.gov.cn/zwgk/zcwj/flfg/art/2022/art_04a0f1fb5df244e39688fd5372623a8d.html) · [促进和规范数据跨境流动规定](https://www.cac.gov.cn/2024-03/22/c_1712776611775634.htm)

## 用户流程

1. 输入 2–128 个 Unicode 字符的关键词、事件描述或问题，选择当前可用的搜索来源及时间范围。系统保留原词，自动提取可用的人物、机构、地点、事件和明确时间，并最多补查两组关键词。
2. 模型可按相关性重排索引返回的候选。列表展示最多 10 条结果，含媒体/域名、可确认的发布时间、摘要、原文链接及“分析这篇”。未知日期明确标注，不根据摘要或相对时间猜测。去掉常见追踪参数后按 URL 去重，保留路径大小写。
3. 点击“分析这篇”自动带入链接并读取正文。搜索摘要不作为新闻正文送给模型。
4. 访客在这一步登录；关键词、结果和选择只在当前标签页暂存，恢复窗口 30 分钟。邮箱验证码首次注册、已有密码和通行密钥登录均可通过固定的 `/login?callbackUrl=/` 回到首页，继续读取所选报道；只允许这一明确的内部返回目标。
5. 搜索结果展示正文及现有后端报价，确认后点击“开始观隅分析”。RSS 卡片显示当前分析费率，点击“分析这篇”会自动读取、校验并提交正文，无需先点读取或再次提交；访客登录后恢复所选 RSS 新闻。模型不可用、费用无法确认或点数不足时禁用分析按钮；读取失败不创建分析任务，保留已填写正文。客户端防止连续点击重复提交。
6. 来源链接保存于报告 JSON 的 `meta.sourceUrl`，在原文区可打开。非所有者查看报告时，该字段遵循原文公开设置，默认不公开。

正文缺失、访问墙、非新闻或标题事件明显错配时返回错误，不用“材料不足”的占位报告代替。正文校验、模型协议和计费边界见 [新闻正文有效性校验](article-input-validation.md)。

## 来源和管理员设置

在“账号管理 → 系统管理 → 首页新闻搜索”设置：

- **首页默认来源**：免费网页搜索或 DeepSeek API，与报告分析模型/报告核验的来源选择独立。
- **平台 API 密钥来源**：复用模型管理里已经保存的 DeepSeek 搜索密钥，不复制密钥，也不把密钥发到浏览器。所选配置须启用、对用户可见、未归档且已保存搜索密钥。保存新密钥后可刷新配置列表。
- **平台 API 每日调用上限**：默认 200，允许 1–10000。按北京时间及所选配置计数；记录的是上游调用尝试，包括失败尝试，缓存命中不占额度。耗尽时提示改用免费搜索。平台承担服务商搜索费用，不额外扣用户搜索点数。

免费工具查询配置的 SearXNG `categories=news`，并使用 Bing News RSS；两个来源有结果时交错展示、按原文链接去重。没有其他可用结果且 Bing RSS 不可用时尝试 Bing News 网页，新闻来源都不可用时提示失败，不再把普通网页结果当作新闻。RSS 中的媒体、原文链接和明确发布时间会进入结果列表。时间范围同时传给上游，并根据明确的发布时间再次筛选；没有可确认日期或不在范围内的报道不会出现在有时间限制的结果中。新闻索引仍可能漏报，也无法保证所有报道都适合自动提取全文。

首页 DeepSeek 搜索在有可用搜索密钥时开放。`GUANYU_ALLOW_DEEPSEEK_NEWS_SEARCH=false` 可在部署级关闭此入口。访客只能使用免费来源。登录用户如有有效 Pro（含兼容永久 BYOK）或管理员权限，并保存了个人 DeepSeek 搜索密钥，优先使用其个人密钥；否则使用管理员开放的平台配置。无权限的个人密钥不参与解析。管理员没有独立首页密钥时，还可以手动选择使用启用的、配置了 DeepSeek 搜索密钥的平台模型。首页始终标明密钥由个人还是平台提供。

DeepSeek 的搜索接口面向普通网页：首页先查询免费新闻索引，再只展示同时出现在该索引和 DeepSeek 结果中的原文链接，因此结果可能较少；没有新闻候选时不调用付费接口。DeepSeek 当前接口未提供项目可依赖的时间筛选，因此选择该来源时仅允许“不限时间”。失败时提供显式免费搜索按钮；免费搜索不会自动调用收费 API。

## 缓存、限额和成本

- PostgreSQL 的短时共享缓存：有结果 3 分钟、空结果 30 秒。缓存键用 HMAC 表示查询、语言、时间、来源和密钥作用域。缓存结果短时保存启用扩展时采用的变体关键词，不保存原始查询或密钥。个人密钥缓存按账号隔离，平台密钥缓存可在同一配置下共享；密钥轮换使旧缓存失效。
- 数据库锁和 30 秒租约合并相同并发查询；等待者收到 409 与 Retry-After，由页面有限次重试。过期租约可重新取得，旧执行者不能覆盖新缓存。
- 单网络 5 分钟最多 12 次访客请求或 30 次已登录请求（含重试）；收费搜索每账号每 10 分钟最多 10 次新的上游尝试，另受平台每日限额约束。
- 索引请求写入 `ModelUsageEvent.operation=news_search`，关键词提取和排序用量写入 `news_search_ai`。缓存命中复用已有结果，搜索不创建分析扣费账单。
- 模型使用支持分析的已启用平台模型，优先使用首页搜索选定的平台配置，否则使用平台默认模型。模型只接收查询和候选新闻的公开标题、摘要、来源与日期，排序只能使用服务端提供的编号。
- `NEWS_SEARCH_AI_DAILY_LIMIT` 按北京时间限制平台每天增强的未缓存搜索量，默认 200，设为 0 可停用增强。一次增强最多调用两次模型。无可用模型、超时或响应无效时，仍保留原词及索引结果。
- 查询通过 POST 请求发送，不进入站内 URL。缓存结果会短时保存公开标题、链接和摘要，过期缓存由现有每日 `/api/cron/privacy` 清理；有效期与物理清理时间不同。

## 部署

先应用 `prisma/migrations/20261025_news_search/migration.sql`，再启动新代码。新增 AppSetting 的三个字段和 NewsSearchCache 表/索引，不修改旧报告、用户余额或密钥。遵循现有 `prisma migrate deploy` 流程；早期 db-push 建库需先完成迁移历史基线，不要重置生产库。空库验证使用 `prisma db push`。

默认无需收费 API。可选部署变量继续复用：

```dotenv
WEB_RESEARCH_SEARXNG_URL=https://your-searxng.example
WEB_RESEARCH_ALLOW_PRIVATE_SEARXNG=false
GUANYU_ALLOW_DEEPSEEK_NEWS_SEARCH=false
```

只有部署者控制的内网 SearXNG 才应启用私网访问。保留现有 SSRF、重定向、响应体和超时限制，正常抓取不放开私网。生产公开请求依赖可信代理限流（Vercel 自动识别；自托管沿用 TRUST_PROXY_HEADERS 配置）。

如果页面提示“新闻搜索服务配置不完整”，检查服务日志中的 `[news-search]` 代理配置提示。自托管部署应让可信反向代理覆盖 `X-Forwarded-For` 和 `X-Forwarded-Proto`，再设置 `TRUST_PROXY_HEADERS=true`；不要在没有可信代理保护的服务上启用该选项。

## 验证与限制

`npm run test:home-news` 覆盖图片候选与签名、实际图片解码及大小限制、多源聚合 / 误匹配 / 时效 / 发布者去重、索引故障、数据库缓存过期与个人作用域隔离、访客无扣费，并已纳入 CI。

`npm run test:news-search` 覆盖 RSS 的原文链接、来源和日期，新闻来源聚合去重、时间过滤、拒绝普通网页回退及 DeepSeek 的新闻索引交叉校验；还覆盖登录恢复、隐私权限、缓存并发、限额与计费，已纳入 CI。旧版普通网页回退的缓存和本地搜索草稿不会继续作为新闻结果显示。

浏览器 QA 使用受控的 SearXNG 兼容 HTTP 服务和本地模型完成真实任务保存/单次扣费；正文提取响应使用虚构报道 fixture。也检查桌面/手机、登录恢复、空结果、旧请求回写、来源故障、RSS 图文卡片、来源筛选、热点依据、最新排序、加载更多、失败状态与访客登录恢复和管理员保存。真实 Bing News 页面与发布者 RSS / 文章配图另行获取并验证解析；首页视觉 QA 使用这些真实公开样本及其原始关联照片，任务与扣费使用明确标识的虚构新闻。云环境只支持代理外联，现有固定公网 IP 直连抓取在此环境受限。DeepSeek 使用测试响应验证，不产生真实计费调用。

免费引擎的页面结构、验证码、站点访问限制和搜索结果时效仍取决于上游。较大流量建议部署并维护 SearXNG；本版不承诺全文索引覆盖、全网热点覆盖、无限分页或根据搜索摘要生成报告。

## 新闻入口后备与事件追问

Bing 新闻 RSS / 卡片不可用时，会尝试 Brave 的新闻页面，仍只展示可识别的新闻条目，不改用普通网页列表。报告内的关键词规划、事件追问、实际来源和离线选择见 [事件追问与关键词检索](event-followup.md)。
