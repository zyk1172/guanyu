# 事件追问与关键词检索

追问可以围绕新闻事件的背景、具体言论、官方声明、其他报道、时间线和后续进展展开。已有报告提供上下文，不再把回答限制在旧报告已写出的结论里。

## 使用方式

- 报告中的“同一事件的其他报道”默认填写简短事件关键词。用户可以修改人物、机构或事件重点，不必复制带有日期前缀和评论性描述的整条标题。执行时由当前模型规划不同关键词组合，再读取候选文章作同事件对照。
- “追问事件与报告”默认勾选“联网查找事件资料”。事件事实问题会尝试联网；解释、总结或改写已有报告时可以不检索。取消勾选后只依据现有材料回答。
- 每个回答显示本轮检索状态，可展开查看实际关键词与来源。来源区分“已读取正文”和“仅检索摘要，未读到全文”；网页打不开时不会将摘要标成已阅读全文。
- 无结果、服务故障与未联网分别显示。若管理员将当前模型设置为离线，页面说明需要切换到启用联网的模型；自定义模型的部署级关闭设置继续生效。
- 网络中断或模型失败后保留问题。同一问题在相同语言、联网选择下重试会沿用请求标识，取回已保存结果或重试失败尝试，避免创建两笔成功扣费。收到 202 时显示“仍在生成”，不追加空回答。

例如，长标题“10.30日：皇马就姆巴佩辱华事件公开低头，官网仍用其封面言行不一，中国市场后续承压”可先形成“皇马 姆巴佩 辱华”的种子，再根据当前问题生成“皇马 姆巴佩 言论”“姆巴佩 官方 声明”等检索组合。这只是关键词示例，不表示确认标题中的说法。

## 执行链路

1. 继续使用账号当前激活的追问模型，先进行一次有界、轻量的关键词规划；最终回答仍使用账号选择的思考强度。规划输入包含标题、文章片段、当前问题和最近对话；所有材料都作为不可信数据处理。
2. 最多规划三个简短查询。完整长标题、明显的 URL、邮箱和密钥赋值不直接作为规划结果使用。规划失败或格式不合格时使用短关键词后备，不因此关闭事件检索。
3. 通常先用不限定日期的组合，再允许带原文声称的年月，减少错误日期让所有查询落空的情况。不同组合的候选轮流纳入，避免第一页结果占满全部阅读名额。
4. 追问预先检索并尝试读取最多三个网页，再将实际资料交给回答模型。“平台联网”模式与不支持函数调用的兼容模型也能获得这些资料。
5. 自主查证模式保留原有搜索/阅读工具及调用上限。兼容模型拒绝工具请求并返回 400/422 时，可用同一模型、同一配置和已取得资料重试普通回答；不会偷偷换模型。
6. 新来源链接以真实返回的来源为准。模型给出的未检索到的 Markdown 链接不会作为可点击来源保留。旧报告、转载、其他年份或同一人物的其他事件不能自动视为本次事件的证明；没有找到具体言论或声明时必须明确缺口。

关键词规划、搜索、阅读和回答有共同的时间与调用预算。额外的规划用量与回答用量累计到统计中；请求次数包含失败的引擎尝试。追问仍按原有费率结算一个服务操作，模型生成失败释放预扣，成功结果及检索元信息一起保存以支持幂等重试。检索为空或不可用时仍可生成带限制说明的回答；若回答成功，按原追问费率计费，不承诺所有搜索失败都免费。

## 免费搜索后备

配置的 SearXNG 仍优先。没有可用自托管入口时：

- 普通网页检索：Bing → Brave 公共网页 → DuckDuckGo HTML/Lite。
- 新闻检索：Bing News RSS → Bing 新闻卡片 → Brave 新闻页面。只把新闻卡片识别为新闻，不把普通网页搜索结果填进新闻列表。

Brave 使用公共页面，不需要收费 API Key，不运行网页脚本或浏览器。仅有相对时间的结果不会被转换为虚构的精确发布时间；严格时间筛选仍排除无法确认日期的结果。免费搜索不会自动调用 DeepSeek 或其他收费搜索接口；已有的显式付费启用与账号/平台密钥选择保持有效。

中文网页在未声明编码且字节为有效 UTF-8 时按 UTF-8 读取；已有 HTTP/meta 编码声明继续优先。原有 SSRF、私网、重定向、响应大小和验证码限制保持生效，不尝试绕过访问控制。

## 兼容与验证

不新增数据库迁移、环境变量或运行时依赖。检索状态和实际关键词作为现有结果 JSON 的可选字段保存，旧结果仍可读取。公开报告的追问只使用页面已公开的材料，不向规划或回答模型传递隐藏原文、隐藏引文和作者私有补充。

- `npm run test:event-followup`：关键词规划、资料预取、来源标签、离线策略、兼容模型后备、累计用量；真实 HTTP 夹具和隔离数据库验证鉴权、CSRF、缓存结果、单次扣费、失败退款与隐藏原文边界。
- `npm run test:web-research`：免费入口后备、Brave 新闻/网页解析、验证码、编码、链接、八种模型工具协议与调用预算。
- `npm run test:related-coverage` / `npm run test:related-coverage-db`：候选正文读取、重复排除、同事件匹配、引文验证、缓存和失败退款。
- `npm run test:news-search`：新闻列表、来源、日期、索引聚合及普通网页不冒充新闻。

免费入口仍受上游页面结构、网络、限流和站点访问控制影响。检索到候选报道不等于核实其内容；模型判断和最新进展也不能仅靠测试夹具证明。
