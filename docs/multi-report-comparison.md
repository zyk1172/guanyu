# 多报道对比

入口：我的审视 → 多报道对比，或 `/compare`。选择最近报告，也可填写本站报告链接/编号。一次限 2–3 份不同报告；服务端每次读取或生成前检查所有材料为本人或公开报告。

对照主张、证据、缺口与核验路径不扣点。它展示保存的审读结果，不是重新阅读全文；未列出不能证明原报道没有提及，重复主张也不等于独立证实。

AI 综合复用现有追问模型、倍率、额度和失败退款机制，使用有长度上限的保存报告快照。模型不执行新的联网搜索。所有综合条目必须引用有效报告编号，相同主张至少引用两份不同报告。无法验证结构/引用时退回预扣点数。

页面读取材料指纹，生成前再次核对；材料被更新时要求重新打开对照，本次不计费。引用在新标签页打开原报告，保留对照工作台。

综合保存在本人 `ServiceOperation` 中。同一组报告内容与版本、界面语言、核查重点复用已完成结果，不重复扣点。材料顺序或浏览计数变化不触发再次计费；改变材料、报告内容/版本、语言或重点会生成新的任务。已保存结果保留其原模型及收费信息；切换默认模型本身不覆盖已有综合。正在处理的任务返回处理中状态，失败任务可重试。

公开材料后续转私有或被删除时，服务端先重新检查访问权限，再决定能否读取缓存。没有公共分享综合结果的入口。已有各个报告的导出流程继续使用原有计费规则。

本批没有数据库迁移；依赖第 3 批的成本记录字段。专题持续监测与团队工作空间仍列在后续路线图中。
