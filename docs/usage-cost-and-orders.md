# 搜索成本与订单状态

## 部署

本批新增 `ModelUsageEvent.estimatedSearchCostMicros`、`costCoverage`、`costBreakdownJson`。已有部署先执行 `prisma migrate deploy`，再启动新应用。超级管理员模型管理页的兼容初始化也支持添加这些列。历史记录默认 `legacy_partial`，不会被反推成完整成本。

本仓库的迁移历史沿用了已有初始数据库，并未包含完整的初始建表迁移；全新本地测试库使用 `prisma db push`。不要对有业务数据的数据库使用 reset 或无审查的 db push。

## 费用配置与口径

`SEARCH_UNIT_COST_MICROS_JSON` 是非敏感环境变量：键为 `tavily_basic`、`tavily_advanced`、`serper`、`searxng`、`duckduckgo`，值为每次请求的美元百万分之一整数。按自己的合同/账单配置，不提供推测性的默认价格。显式的零表示已配置零请求费用；缺少付费提供方价格表示未知。免费 SearXNG、Bing 网页与 DuckDuckGo 的搜索 API 请求费用默认按零记录，仍统计实际请求次数；自托管服务的服务器和流量成本不在此口径内。

记录实际发起的搜索请求，包括失败尝试、多引擎请求和模型工具调用，排除工具缓存命中。费用仍是按请求估算，不是服务商已确认账单：超时、套餐、缓存折扣和失败计费政策可能使实际费用不同。记录当时的提供方次数、搜索费率、模型费率与缺失项，后续修改配置不改变历史快照。

管理员统计合计既有模型/原生搜索估算与已配置的外部搜索估算。未报告的 token、缓存价格、未配置的价格等会标记成本不完整；基础设施、支付手续费、邮件、人工支持等不在此口径内，不能据此宣称净利润。

## 订单

用户只能读取自己的最近订单。PENDING（包括历史 pending）申请可以取消，重复取消幂等。取消与管理员确认/拒绝共用订单事务锁，已付款处理中或已到账订单不允许用户取消。

取消只关闭申请，不自动退款，不改变点数账本。页面明确提示已经转账的用户联系管理员核对退款。FULFILLED/历史 confirmed 展示到账信息；REFUNDED 不展示为已到账。金额和套餐权益仍来自服务端订单快照。
